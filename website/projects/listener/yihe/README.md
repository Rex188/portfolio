# Listener — 单地点原型 / 颐和路

从空白页面重新实现；不依赖旧地图原型、外部字体或前端框架。仅供本地预览，尚未部署。

运行：`python3 serve.py`，打开 http://127.0.0.1:8767/ 。此服务器支持媒体字节范围请求，可可靠拖动进度。

## 已落实的设计

- 约31秒现场延时摄影持续静音循环，压暗作为全屏背景。
- 点击开始后听原声，由观众主动切换到 VCV；1.2秒交叉淡化。
- 切换时按相同秒数对齐；暂停停止声音，背景继续播放。
- 播放/暂停、声音选择、进度、音量、中英文切换、可展开录音说明。
- 地点 description 不代写。作者在 `place.js` 的 `description.en` / `description.zh` 填写，保留换行；空白时不显示占位文字。
- 后续地点可沿用此结构，替换素材、地点配置与录音说明。

## 声音变化进度线

`analyze_audio.py` 使用 NumPy 与 FFmpeg 离线分析两份实际音频，生成 `assets/audio-change.json` 和浏览器使用的 `assets/audio-change.js`。页面根据当前声源展示各自曲线，播放过的部分高亮，支持点击、拖动和键盘定位。没有实时跳动或随机装饰数据。

曲线依据归一化频谱形状、秒内变化与最近120秒的重复材料比较，表示相对声学变化，不能确认新声源或 patch 录音事件。方法、局限与候选时间见 `audio-analysis.md`。合成重复信号加入新频率成分的验证通过；同一信号整体衰减至四分之一时分析分数不变。两份录音独立归一化，曲线高度不可用于跨录音绝对比较。

复现：`python3 analyze_audio.py --ffmpeg /path/to/ffmpeg`（该 Python 环境需有 NumPy）。


正式网站副本：从 website/ 运行 python3 serve.py，然后访问 /projects/listener/yihe/ 。所有运行素材使用相对路径，部署无需连接外部盘。

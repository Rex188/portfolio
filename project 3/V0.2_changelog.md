# Project 3 V0.2 改动记录

文件：`Project_3-V0.2.vcv`，在 `Project_3-V0.1.2.vcv` 的基础上改出来，原文件没有动过。
模块数从 134 变成 119（删 16 个，加 1 个），线从 226 变成 188（删 40 根死线；接限幅器时拆 2 根、新接 4 根）。

## 改了什么

**1. 删掉 16 个没有作用的模块，以及接在它们上面的 40 根线**
- 8vert × 4：`#6068` `#1408` `#5443` `#5075`
- Edge × 5：`#4907` `#0543` `#6811` `#5124` `#5023`
- Slew × 3：`#8635` `#2859` `#4269`
- SampleHold × 2：`#0587` `#3431`
- `CVD#3980` 和 `Rescale#6078`：原来负责往 Brainwash 的 R 声道送包络，但 R 声道放出来以后没有接到任何地方。

8 个 Scope 都留着。删完以后，Brainwash 的 R 输入是空的，所以 Memory 里录进去的 R 声道是静音。原来那一路本来就没接到任何东西，听起来不会有区别。

**2. 录音锁从 241 秒缩到 45 秒**
`EventTimer#9252` 的 length 从 241 改成 45，count 也设成 45，并改成"未运行"的状态。所以打开补丁后，第一次起音就会录音，之后每 45 秒最多重录一次。

**3. 打开音频接口的 DC filter**
`AudioInterface#3292`（Audient iD14），对应右键菜单里的 DC blocker。

**4. 加了一个限幅器：Bogaudio LMTR**
- 用的是 Bogaudio 插件里的模块，你已经装了，不用另装插件。
- 位置：第 4 行 x=84，在 `DGate#5003` 右边，那块原来是空的。
- 接法：总 VCA `VCA-1#7425/#2061` → **LMTR** → `Rescale#8661/#3767`（原来那道 ±5V 硬削波）→ 输出 1/2。
- 设置：threshold 0 dB（旋钮 0.8）、soft knee、output gain 0、attack 5 ms、release 300 ms（后两项在右键菜单里）。
- 为什么放在 Rescale 前面：如果放在硬削波后面，信号已经被削过了，限幅器既拦不住失真，也碰不到 ±5V 以上的信号，等于没用。现在的顺序是：限幅器先把音量压下来，Rescale 硬削波留作最后保险。如果你想要严格放在 Rescale 后面，挪 4 根线就行。
- 关于 −1 dBFS：VCV 里 ±10V 才是满刻度，原来的 Rescale 把信号卡在 ±5V，也就是大约 −6 dBFS，所以输出峰值本来就到不了 −1 dBFS。LMTR 的 0 dB 是按 5V 算的，检测的是左右相加后的 RMS，所以它在信号接近 ±5V 之前就会开始压。要让输出真正能到接近 −1 dBFS，得把两个 Rescale 的上下限放宽到 ±8.9V 左右，这一步我没做，由你决定。

## 没有动、等你决定的
- 两个 DADSRH 还开着 **Slow** 档：`DADSRH#0251` hold 实际是 30 秒（回应锁），`DADSRH#6932` hold 实际是 15 秒（总输出窗口）。是不是你想要的，你来定。
- 两个 Rescale 硬削波（±5V）保持不变。
- 其他所有参数、线和位置都没改，包括 Tehom、Ruminate 速度、阈值、Delay、Plateau。

## 先听什么（最好先戴耳机测）
1. **能不能正常打开**：Rack 加载时没有报 missing module，最右边能看到 LMTR，全部 8 个 Scope 都在。
2. **录音锁**：出一次声，确认 Brainwash 录了；45 秒内再出声应该不会重录，45 秒后可以。可以看 EventTimer 的数字倒数。
3. **限幅器**：LMTR 面板上没有压缩指示灯，所以拿 Scope 对比 LMTR 前后的电平：正常说话时前后应该差不多，只有大声说话或拍手时输出才被压低。如果平时说话也一直被压，说明压得太狠，把 threshold 往上调（比如 +3 dB，也就是旋钮 0.9）。听一下大声时的削波声比 V0.1.2 少了没有。
4. **整体声音**：同一段输入，对比 V0.1.2 和 V0.2，除了响度和削波，其他应该听不出区别。如果有明显不同，告诉我。
5. **DC filter**：静音时输出电平应该在 0 附近，没有直流偏移。
